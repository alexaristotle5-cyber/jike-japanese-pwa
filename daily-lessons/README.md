# JLPT N2 每日课程库

这是“即刻日语 PWA”的每日系统课程目录，用于从 N5/N4 起点持续训练到 2026-12-07 JLPT N2。

## 固定训练结构

每节约 30 分钟：

1. 旧知识热身
2. 6—10 个核心词汇
3. 1 个核心语法及易混辨析
4. 书面语 / 日常口语 / 动漫化表达对比
5. 短篇阅读
6. 选择、翻译、造句等实际作答
7. 每题留答题区，随后提供答案与解析
8. 一个明确的下一步

## 目录约定

- `public/daily-lessons/index.html`：可在 GitHub Pages 打开的课程网页。
- `public/daily-lessons/lessons/index.json`：课程总索引。
- `public/daily-lessons/lessons/YYYY-MM-DD-day-XX.json`：每日结构化课程数据。
- `daily-lessons/lesson-template.md`：后续课程制作规范。

## 语音规则

网页中的每个日语句子和题目都提供播放按钮：

- 优先使用 HTTPS 在线日语语音源；
- 在线语音失败时回退到浏览器 `speechSynthesis`；
- 支持正常速度与慢速跟读；
- 长文本按句切分，避免一次加载过长。

## 内容规则

- 汉字后标注平假名，例如：理解(りかい)する。
- 单独保存适合朗读的纯日语文本，避免 TTS 读出中文解释。
- 明确区分考试书面语、现实自然口语、动漫化夸张表达。
- 每道题必须包含：题目、答题空间、答案、词汇/语法解析。
- 新课程通过课程索引按日期追加，不覆盖旧课程。
